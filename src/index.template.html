    從開始畫面選擇

    匯入自己的單檔 HTML，或先用內建範例熟悉調整方式。

    試玩內建範例

    在開始畫面選「試玩內建範例」，熟悉點選、拖曳與右側調整面板。

    1. 點畫面上的文字、區塊、雙星光、摘要卡、按鈕或導覽項目。
    2. 直接拖動選中的元素；拉選取框右下角，可以等比例放大或縮小。
    3. 右側可以微調位置、大小、顏色、圓角與陰影；不同元素只顯示適合它的項目。
    4. 用復原／重做回頭；右上角「調整紀錄」會把 CSS 數字翻成容易理解的變更。

    匯入 HTML 檔

    需要一個不超過 5 MiB、內容都放在同一個檔案裡的 .html 或 .htm。網址、ZIP、資料夾與框架專案不能直接匯入。

    1. 在開始畫面按「匯入 HTML 檔」，或在工作臺使用同名按鈕，選擇手機或電腦裡的單檔 HTML 副本。
    2. 檔案只會在瀏覽器中開啟，不會上傳，也不會覆寫原始檔。
    3. 在預覽裡點選元素；右側會分開顯示外觀能否修改，以及原始互動是否停用。
    4. 完成後按「下載修改後 HTML」。若按鈕沒有開放，畫面會說明尚未通過哪一項安全檢查。
    5. 下載的是新的 .lts-edited.html 檔案；Studio 不會自動替你發布網站。
    外觀可修改：可安全調整文字或允許的 CSS 外觀。 互動已停用：按鈕、連結與表單不會執行原始行為，但支援的外觀仍可修改。 已封鎖 blocked：危險或不支援的能力已停用，並且不能下載修改後的 HTML。
