兩種開始方式

先玩內建示範，或修改自己的單檔 HTML；不需要懂 CSS。

先玩內建示範

適合第一次打開 Studio，先熟悉點選、拖曳與右側調整面板。

  1. 點畫面上的文字、區塊、雙星光、摘要卡、按鈕或導覽項目。
  2. 直接拖動選中的元素；拉選取框右下角，可以等比例放大或縮小。
  3. 右側可以微調位置、大小、顏色、圓角與陰影；不同元素只顯示適合它的項目。
  4. 用復原／重做回頭；「查看調整摘要」會把 CSS 數字翻成容易理解的變更。

修改自己的頁面

需要一個不超過 5 MiB、內容都放在同一個檔案裡的 .html 或 .htm。網址、ZIP、資料夾與框架專案不能直接匯入。

  1. 按工作臺上方的「修改 HTML」，選擇手機或電腦裡的 HTML 副本。
  2. Studio 只會在瀏覽器裡讀取暫時副本，不會上傳，也不會覆寫原始檔。
  3. 在預覽裡點選「可修改 safe」元素，再從右側調整文字、外觀、位置或大小。
  4. 完成後按「下載修改後 HTML」。若按鈕沒有開放，畫面會說明尚未通過哪一項安全檢查。
  5. 下載的是新的 .lts-edited.html 檔案；Studio 不會自動替你發布網站。
可修改 safe：可以選取並調整。 僅查看 view-only：可以查看，但不會被改動。 已封鎖 blocked：危險或不支援的能力已停用，並且不能下載修改後的 HTML。
