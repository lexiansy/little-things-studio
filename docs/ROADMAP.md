# Roadmap

## Current: v0.1.0-beta.1 public beta prerelease

- Clean public-facing repository history
- Standalone local-first application
- Fictional, generic built-in sample content
- Safe/view-only/blocked HTML import classification
- Session-only safe editing
- Gated edited-copy export and reopen
- Public documentation, contribution guidance, security policy, and CI

## Public-beta follow-ups

- Owner and release-steward visual acceptance of the reissued generic screenshot, release asset, and live demo
- Accessibility and keyboard-flow review
- Clearer diagnostics for unsupported structures
- Additional deterministic fixtures and browser regression coverage

## Deliberately not scheduled

- Arbitrary website or framework import
- Multi-file project or PWA mode
- Imported script execution
- Direct writeback to original files
- Remote fetching, accounts, collaboration, or additional hosting/deployment targets

Roadmap items are directions, not commitments. Each construction batch requires its own branch, scope, and validation evidence.
